Многопользовательская информационная система для администрирования базы данных городов, управления их климатическими, географическими и демографическими показателями. 

Проект реализован с использованием **Spring MVC** и **Hibernate**, включает бизнес-логику транзакций и синхронизацию состояния данных между клиентами в реальном времени.

## Технологический стек

* **Backend:** Java, Spring Framework (Spring MVC, Spring Core)
* **Data Access:** JPA, Hibernate ORM
* **Database:** PostgreSQL
* **Архитектура:** N-Tier Architecture (Controller, Service, Repository)

## Основной функционал

### 1. Управление данными (CRUD)
* Создание, чтение, обновление и удаление объектов `City` и связанных сущностей (`Coordinates`, `Human`).
* Валидация вводимых данных на уровне интерфейса, бизнес-логики и базы данных.
* Защита целостности данных: блокировка удаления объектов, если на них ссылаются другие записи в БД.

### 2. Multi-user синхронизация
Реализована реактивная система обновлений: при добавлении, изменении или удалении записи одним пользователем, таблица и интерфейсы мгновенно и автоматически обновляются у всех остальных авторизованных клиентов.

### 3. Бизнес-логика 
Специальные операции реализованы на уровне логики приложения:
* **Аналитика:** Вычисление суммы, фильтрация по порогу и сбор уникальных значений географического показателя (`metersAboveSeaLevel`).
* **Транзакции:** Миграция населения. Безопасное «переселение» 100% жителей из указанного города в город с наименьшим населением.
* **Массовые операции:** Распределение 50% жителей столицы в три самых малонаселенных города системы.
